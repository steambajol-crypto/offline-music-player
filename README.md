# Offline Music Player (Python)

A simple offline desktop music player built with Python, PySide6, and VLC.

## Features
- Play local audio files
- Play / Pause / Next / Previous controls
- Seek bar and time display
- Volume control
- Playlist support
- Background playback

## Tech Stack
- Python
- PySide6
- python-vlc

## Project Structure
- `app.py` — app entry point
- `ui_main.py` — user interface
- `player.py` — playback logic
- `playlist.py` — playlist save/load logic
